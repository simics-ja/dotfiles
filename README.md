# My dotfiles

## Usage

```bash
git clone https://github.com/simics-ja/dotfiles.git
cd dotfiles
sh setup.sh
```

## Option

### local config

**WSL:**

```bash
sh setup_scripts/wsl.sh
```

The script copies the WSL samples to `git/local` and `zsh/.zshrc.local` without overwriting existing local settings.
